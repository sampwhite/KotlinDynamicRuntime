# @endpointList
# +whatIsThis
Every endpoint you may call, as this site describes it: its path, what it takes, and what it answers. One you may not
call is not listed. Select one to see its input and output, and to call it from a form.

A program calls the same endpoints with an API key. [Using the API](/docs/api-guide.md) says how: what a client is
made of, what every call has in common, and a recipe for each job. Who may call each part of the API is in
[the roles and access reference](/docs/reference/roles-and-access.md).
