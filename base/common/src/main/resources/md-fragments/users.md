# @userList
# +whatIsThis
Each row is a user you administer, or, if you are an editor, a user of your client. A user is one person's account in
one client: a person with one address may have several, one per client or persona. Select a row to see the user and,
if you administer them, to change their access, their labels, or how they sign in.

What each role grants, who may call each part of the API, and whose data a user reads are in
[the roles and access reference](/docs/reference/roles-and-access.md).
